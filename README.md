# CredFlow

CredFlow is a futuristic fintech-style React application built with Vite.  
It provides a modern digital payment dashboard experience with wallet management, QR payments, invoices, deposits, and transaction tracking.

---

# Features

- Modern futuristic UI
- Responsive mobile-first design
- React + Vite architecture
- Wallet dashboard
- QR payment system
- Send & receive payments
- Deposit management
- Invoice generation
- Transaction cards
- Animated interface
- Fast loading performance
- Modular component structure
- GitHub & Vercel deployment ready

---

# Tech Stack

- React.js
- Vite
- JavaScript
- CSS3
- React Router DOM
- Framer Motion
- Lucide React Icons
